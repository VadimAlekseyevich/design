# Лабораторная работа №2 — вариант 2

Студент: Шилин В.А.

Приложение Windows Forms (.NET Framework) для настройки компонента Label через модальное окно.

Настраиваемые свойства варианта 2:
- Text
- BorderStyle
- TextAlign
- Enabled

Главная форма расположена по центру экрана. Диалог настройки открывается по центру родительской формы и не отображается на панели задач. Обмен данными между формами двусторонний: перед открытием диалога его элементы управления получают текущее состояние Label, а после подтверждения значения применяются обратно к Label.
